Dockerin perusteet

< Takaisin etusivulle

1. Mikä Docker on?

Docker pakkaa sovelluksen ja sen tarvitsemat tiedostot samaan helposti siirrettävään kokonaisuuteen. Tätä kokonaisuutta kutsutaan kontiksi. Kontti käyttää isäntäkoneen käyttöjärjestelmän ydintä, mutta sen prosessit ja tiedostot pysyvät erillään muista sovelluksista.

Ajattele asiaa näin: image on valmis resepti tai muotti, ja kontti on siitä käynnistetty sovellus. Samasta imagesta voi käynnistää useita kontteja.

2. Image, kontti ja Dockerfile

Image sisältää sovelluksen suorittamiseen tarvittavat tiedostot. Dockerfile kertoo, miten image rakennetaan. Kun docker run -komento suoritetaan, Docker luo imagen perusteella uuden kontin ja käynnistää sen.

Tämän repositoryn web-palvelun Dockerfile on hyvin pieni:

FROM nginx:alpine
COPY html/ /usr/share/nginx/html/
  • FROM valitsee pohjaksi kevyen nginx-imagen.
  • COPY siirtää tämän projektin web/html/-kansion nginxin tarjoiltavaksi.

Myös muistiinpanojen API rakennetaan omasta Dockerfilesta. Se käyttää Node.js:n Alpine-imagea, asentaa package.json-tiedoston riippuvuudet ja käynnistää server.js-tiedoston. Näin sama perusidea toimii eri sovelluksille.

3. Imagen rakentaminen ja kontin käynnistäminen

Kun komento suoritetaan tämän repositoryn juurikansiosta, web-palvelun imagen voi rakentaa ja käynnistää näin:

docker build -t docker-rojekti-web ./web
docker run --rm -p 80:80 docker-rojekti-web

Tämä komento toimii tässä repositoriossa, koska ./web määrittää rakennuskontekstiksi web/-kansion. Kansiossa ovat sekä Dockerfile että html/-kansio, joten Docker löytää Dockerfilen ja COPY html/ -komennon tarvitsemat tiedostot.

Jos olet jo web-kansiossa, vastaava komento on docker build -t docker-rojekti-web .. Piste tarkoittaa nykyistä kansiota.

-t antaa imagelle nimen. docker run käynnistää imagesta kontin, --rm poistaa kontin pysäyttämisen jälkeen ja -p 80:80 yhdistää oman koneen portin 80 kontin nginx-porttiin 80. Tämän jälkeen sivu avautuu osoitteessa http://localhost.

4. Kontin elinkaari

# Käynnistä web-kontti
docker run --name web-kontti -p 80:80 docker-rojekti-web

# Näytä käynnissä olevat kontit
docker ps

# Näytä myös pysähtyneet kontit
docker ps -a

# Näytä kontin lokit
docker logs web-kontti

# Pysäytä kontti
docker stop web-kontti

# Poista pysäytetty kontti
docker rm web-kontti

Image ja kontti ovat eri asioita: kontin voi poistaa ilman että image poistuu. Imagen voi tarkistaa komennolla docker image ls ja poistaa tarvittaessa komennolla docker image rm docker-rojekti-web.

5. Mitä kontissa tapahtuu?

Kontti suorittaa yhden pääprosessin. Tässä esimerkissä nginx-palvelin tarjoaa html/-kansion tiedostoja. Kun nginx-prosessi päättyy, kontti pysähtyy. Kontin voi käynnistää uudelleen komennolla docker start web-kontti.

Kontti ei ole sama asia kuin virtuaalikone. Kontti on yleensä kevyempi ja käynnistyy nopeasti, koska se käyttää isäntäkoneen Docker-ympäristöä eikä sisällä kokonaista omaa käyttöjärjestelmää.

6. Tiivistelmä

  • Dockerfile kertoo, miten image rakennetaan.
  • Image on sovelluksen valmis paketti.
  • Kontti on imagesta käynnistetty suoritettava instanssi.
  • docker build rakentaa imagen ja docker run käynnistää kontin.
