1. Docker ja Kontitus

Docker mahdollistaa sovellusten ja niiden riippuvuuksien sulkemisen standardoituun pakettiin eli konttiin.

docker run -d -p 80:80 nginx

Imaget, kontit ja kerrokset

Image on kontin malli, ja kontti on sen käynnistetty instanssi. Image rakentuu kerroksina: jokainen Dockerfile-komento luo oman kerroksensa, jotka jaetaan kaikkien saman imagen perusteella pyörivien konttien kesken.

Tämän projektin web-kontti perustuu nginx:alpine-imageen, joka on kevyt Linux-jakelu nginx-palvelimen kera.
