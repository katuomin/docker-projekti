2. Docker Compose

Kun sovellus koostuu useasta palvelusta, käytetään Docker Composea. Sen avulla koko mikropalveluympäristö käynnistetään yhdellä komennolla.

docker compose up --build -d

Tämän projektin compose-tiedosto

Projekti koostuu viidestä palvelusta: web (nginx), proxy (nginx-reititys), notes-api (Node/Express), database (PostgreSQL) sekä nimenvolyymi pgdata. Palvelut on jaettu kahteen verkkoon: frontend-network ja backend-network (internal), jolloin tietokantaan ei pääse ulkopuolelta.

depends_on ja healthcheck varmistavat, että palvelut käynnistyvät oikeassa järjestyksessä.
