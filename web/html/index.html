Mitä on Docker ja Mikropalvelut?

Tämä sivu pyörii omassa Nginx-kontissaan. Se on osa mikropalveluympäristöä, jonka muut osat käsittelevät dataa taustalla.

1. Docker ja Kontitus

Docker mahdollistaa sovellusten ja niiden riippuvuuksien sulkemisen standardoituun pakettiin eli konttiin.

docker run -d -p 80:80 nginx

2. Docker Compose

Kun sovellus koostuu useasta palvelusta, käytetään Docker Composea. Sen avulla koko mikropalveluympäristö käynnistetään yhdellä komennolla.

docker compose up --build -d
